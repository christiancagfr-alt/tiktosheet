# Google 脚本版：首次部署，之后直接同步

不需要服务账号 JSON、不需要本机后端，也不用分别配置令牌。需要用拥有目标表格编辑权限的 Google 账号完成一次脚本授权和部署。插件仍需保存一次脚本完整连接，不能仅凭表格链接获得写入权限。

## 1. 粘贴完整代码

打开目标 Google 表格 → **扩展程序 → Apps Script**。删除默认代码，将本文件夹 **Code.gs 的全部内容**复制到编辑器中并保存。不要只复制 entry.js。

## 2. 添加 Google Sheets 服务

编辑器左侧 **服务 → ＋ → Google Sheets API → 添加**，标识符保留 `Sheets`，版本选择 v4。使用默认 Cloud 项目通常无需另行配置；如项目已改为标准 Google Cloud 项目，还需在对应 Cloud 项目启用 Google Sheets API。

也可以在项目设置中显示 appsscript.json，用提供的同名文件替换清单来启用服务；这与上面的添加服务二选一。

## 3. 初始化与授权

顶部函数列表选择 **setup**，点击运行，按 Google 提示授权你刚创建的脚本访问电子表格。成功后日志显示初始化完成。它自动绑定当前表格并生成授权码，不用填写表格 ID 或私钥到代码里。重复运行不会更换授权码。

## 4. 部署 Web 应用

点击 **部署 → 新建部署 → 类型选择 Web 应用**。

- 执行身份：**我**。
- 谁可以访问：**任何人**（允许未登录调用，不是“仅限我”或“拥有 Google 账号的人”）。

点击部署。脚本通过请求中的授权码验证调用者，并且只写入绑定的表格；不要将完整连接发到公开群聊。若组织策略不允许“任何人”，此方案不能直接使用，需要管理员允许；新版已移除 Node 后端支持。

## 5. 复制一次完整连接

部署后回到编辑器，选择 **showConnection** 并运行。切换回绑定的 Google 表格，在弹窗中复制完整的一行（新版不再将授权码写入执行日志）：

`https://script.google.com/macros/s/部署ID/exec#key=自动生成的授权码`

必须包含 `#key=` 后的全部内容，授权码保存在脚本属性中，只应向可信使用者提供。若你使用显式 appsscript.json 清单，请同步更新清单并授权新增的 script.container.ui（仅用于显示复制弹窗）。

## 6. 插件保存与预览

加载 v0.4.2 插件，在设置中粘贴：脚本完整连接、Google 表格链接、工作表标签名称。设置日期行、账号列、数据起始行，以及四项指标偏移（默认 `0,1,2,3`）。保存时允许浏览器访问 Google 脚本及其返回结果的域名。

默认四项为：关注总数、关注增长、粉丝总数、粉丝增长。表格账号列应存放完整 TikTok 或抖音主页 URL 文本。每个日期块的日期只填写一次，可合并四个表头单元格。前一天必须同样是粉丝口径，不能用互关好友历史数据作为基数。

打开登录账号主页 → 插件自动读取 → **预览写入位置** → 检查 → **同步到表格**。没有昨日数据的增长跳过且保留原单元格；不自动新增日期和账号行；不覆盖公式。日界线按表格设置的时区计算。

其他浏览器配置文件可以复用这条完整连接。多个脚本请求用脚本锁串行处理；人工或其他程序调整表格不受此锁限制。Google Apps Script 有配额和执行时长限制。新版改为每日定时，默认 11:00、Europe/Lisbon，可在插件修改；不再按分钟循环。当天错过后启动浏览器会补打一次。每天每份配置最多自动尝试一次，失败或执行中断后请手动同步；不追补往日数据。打卡时区和表格日期时区是两项独立设置，请保持符合你的业务要求。

## 更新与故障排查

- 更新代码后：部署 → 管理部署 → 编辑 → 版本选择新版本 → 部署。只保存编辑器代码不会更新现有 /exec 部署。
- 返回登录页面或非 JSON：确认执行身份为“我”、访问权限为“任何人”，使用 /exec 而不是 /dev。
- 连接授权无效：重新运行 showConnection，复制包含授权码的完整连接。
- 脚本执行失败：查看左侧执行记录，确认 Sheets 服务已添加、setup 已授权、表格仍可编辑。
- 更换目标表格：在新表格创建并部署独立脚本，再更换插件连接。
- 撤销访问：删除 Web 应用部署；或删除脚本属性 SYNC_KEY 后运行 setup 重新生成授权码（旧连接随即失效）。
