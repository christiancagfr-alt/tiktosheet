# TikTok / 抖音数据智能同步助手 0.4.2

Chrome、Edge、Brave 共用的 Manifest V3 插件，通过 Google Apps Script 同步 Google 表格。已按用户选择移除 Node 中转后端，不再需要服务账号私钥或本机服务。

## 安装与升级

1. 从目标 Google 表格打开 Apps Script，按 [脚本安装说明](apps-script/安装说明.md) 安装完整的 [Code.gs](apps-script/Code.gs)。启用 Sheets 服务。新版 showConnection 在表格弹窗中显示连接，不再写入执行日志；显式清单须同步更新 appsscript.json 的界面权限。
2. 更新已有脚本时，保存代码后到“部署 → 管理部署 → 编辑 → 新版本 → 部署”。保留脚本属性中的绑定 ID 和授权码，无需重新 setup 或轮换密钥。
3. 解压 dist/tiktok-smart-sync-extension-v0.4.2.zip，在 chrome://extensions、edge://extensions 或 brave://extensions 开启开发者模式，加载包含 manifest.json 的目录。更新现有安装则替换原目录文件后重新加载，再刷新 TikTok／抖音页面。
4. 旧 Node 地址不会继续工作。请在插件保存脚本完整连接、表格链接和工作表名称。完整连接含授权码，不要公开分享。

## 数据定位

默认日期行 3、账号列 B、数据起始行 4，均可修改。四项指标偏移默认 0,1,2,3，顺序是关注总数、关注增长、粉丝总数、粉丝增长。日期块首列填一次日期，其余可合并；不要把重复日期子表头设为日期行。

用户当前表格配置为：日期行 **1**、账号列 **B**、起始行 **7**。日期标题从 L 列开始时，写入 L/M/N/O。表头“好友”应按实际口径改为“粉丝”，昨日基数也必须是粉丝数。

账号列存放完整 TikTok https://www.tiktok.com/@用户名 或抖音 /user/… 文本链接。忽略语言查询参数。日期按 Google 表格时区，支持真实日期单元格和 YYYY-MM-DD、M/D、M-D 等文本。缺少昨日值时跳过相应增长单元格，保留原值；真实 0 仍作为有效基数。找不到账号/日期、重复键、越界、覆盖公式都会拒绝。

## 每天自动打卡

勾选“每天按设定时间自动打卡”，设置时间和 IANA 时区，默认 **11:00 / Europe/Lisbon**；中国时间使用 Asia/Shanghai。不再使用固定分钟间隔。

- 浏览器须运行，且有已登录的 TikTok／抖音页面。必要时会临时打开本人主页，读取后关闭。
- 浏览器关闭时无法执行；当天超过时间后启动浏览器会补打一次，不追补过去日期。
- 每份配置每个当地日期自动尝试一次，尝试记录先于网络写入保存。失败或崩溃中断后需手动同步，避免不确定结果下重复提交。
- 浏览器休眠/节能可能延迟闹钟，不能保证秒级准点。夏令时由所选时区计算。
- 打卡时间使用插件时区，写入哪一天使用表格时区。两者应符合你的统计口径。

## 开发验证

第三方 npm 依赖为 0。Node 只用于本地生成和测试，安全最低版本为 22.23.4 / 24.22.1 / 26.12.1（限对应大版本）；推荐 .node-version 中的 24.22.1。

运行 ./scripts/verify.ps1。验证脚本优先使用本项目 .tools/node-v24.22.1/node.exe，否则使用 PATH 中的 Node。本次审核已下载并核验本地副本，但它不打包到分发文件中。

也可在受支持的 Node 环境执行 npm run build、npm run check、npm test、npm audit。scripts/scan-secrets.ps1 会扫描源码与 ZIP（不解压），只输出路径和命中类别，不输出密钥值。

## 安全说明

见 [完整安全审核报告](SECURITY-REVIEW.md)。当前未发现真实硬编码密钥，未检查云端日志、部署及浏览器本地存储。旧版 showConnection 会将密钥写入日志；若日志或连接已外泄，必须撤销/轮换对应凭据，只删除本地代码不足以阻断访问。

历史 dist 文件保留作回溯，未经本轮修复，不要继续分发。每个浏览器固定账号绑定的方案尚待用户决定，现有 DOM 自动身份识别不能作为服务端授权凭证。
